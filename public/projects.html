Honours Project

2026

A vast repository of human knowledge is locked in long visual documents: financial reports, academic papers, and technical manuals, often running to hundreds of pages. This project is on multi-page visually rich document understanding (MP-VRDU), extracting and reasoning over that information given a document's content, structure, and layout.

MP-VRDU is difficult because the evidence needed to answer a question is usually scattered across pages that sit far apart, sits in tables and figures as often as in text, and arrives in documents far longer than a model's context window.

MP-VRDU survey (EMNLP 2026) · Empirical attribution paper (under review)

RAG · VRDU · Agentic planning · Multimodal LLMs · Multi-hop reasoning

Semantic Novel Recommender

2026

A local, offline semantic search engine for Chinese web novels that embeds metadata into 1024-dimensional vectors with BAAI/bge-m3 for exact cosine retrieval. Ranking is hybrid: dense retrieval, a tag-overlap boost, and metadata filters, with an optional local LLM for query parsing and re-ranking. The incremental indexing pipeline scales to over 100,000 novels, and it ships with a FastAPI and React reader app.

Live site

BAAI/bge-m3 · Semantic search · PyTorch · Sentence-Transformers · FastAPI · React

Logarium

2024, rebuilt 2026

A full-stack media tracker that unifies ten media types into one library with consistent statuses, ratings, and cross-format statistics. It searches metadata across 15 external providers concurrently, with normalisation, deduplication, and graceful fallback when a provider fails. The backend is a service-oriented FastAPI and PostgreSQL application with JWT multi-user auth and a personalised recommendation engine.

Live demo, which logs you into a demo account mirroring my personal one. Data is refreshed every 24 hours, so any changes you make will not persist.

React · FastAPI · PostgreSQL · Docker
